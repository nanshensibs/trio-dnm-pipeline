1. Purpose and Scope

This protocol defines a standardised workflow for identifying de novo mutations (DNMs) — variants present in a proband but absent from both biological parents — from trio short-read sequencing, and for characterising their functional consequence. Because >99 % of raw Mendelian-violation calls are technical artefacts, the workflow is built around independent lines of evidence and explicit, auditable filter layers.

The pipeline integrates: (i) pre-flight sample QC with hard stop-gates; (ii) joint trio calling with two independent engines; (iii) multi-caller DNM detection plus an in-pipeline Bayesian posterior; (iv) a layered filter cascade; (v) biological sanity checks; (vi) post-zygotic and parental-mosaic tracks; (vii) functional annotation, calibrated pathogenicity evidence and prioritisation; (viii) somatic mutation analysis; and (ix) orthogonal validation.

Out of scope (require dedicated companion pipelines): structural and copy-number DNMs (e.g. GATK-SV, Manta + CNVnator trio mode), mitochondrial heteroplasmy, short-tandem-repeat expansions (ExpansionHunter), and long-read–only analyses. Somatic analyses are now in scope (§11).

3. Stage 1 — Pre-flight Sample Quality Control

Sample swaps, non-paternity and contamination silently corrupt every downstream DNM call. Stage 1 must pass before variant calling; trio-dnm qc-gate evaluates the gates and exits non-zero on failure, which halts the workflow. The Mendelian-error gate needs the joint call set and is evaluated by trio-dnm call (§3.3). All gate thresholds are in the qc section of the configuration (qc-gate --config, call --config).

3.1 Sequencing-level QC

  • FastQC on all FASTQ, aggregated by MultiQC; flag abnormal GC, adapter content > 5 %, or Q20 base fraction < 90 %.
  • fastp: adapter auto-detection, poly-G trimming (NovaSeq/NextSeq), minimum length 50 bp, low-complexity filter.
  • mosdepth after alignment: WGS mean ≥ 28×; WES ≥ 80× on target with ≥ 90 % of targets at ≥ 20×; coverage CV < 0.30 for WES. qc-gate checks the mean depth (WARN below 28× WGS / 80× WES / 200× panel); target uniformity is reviewed in the MultiQC report.

3.2 Sample identity and relatedness

  • VerifyBamID2 FREEMIX < 0.02 pass; 0.02–0.05 investigate; > 0.05 fail.
  • somalier relate: parent–child relatedness 0.40–0.60 (kinship coefficient ≈ 0.25) and IBS0 ≈ 0 (< 0.5 % of informative sites). Low IBS0 is the discriminating signal — full siblings also show relatedness ≈ 0.5 but have IBS0 > 0.
  • Parents: relatedness < 0.10 unless consanguinity is documented (it changes the prior on inherited homozygosity).
  • Sex inferred from chrY depth ratio and chrX heterozygosity must match the pedigree for all three members (PED father male, mother female): a father/mother label swap leaves both parent–child relatedness values at ≈ 0.5 and is caught only here. A sex that cannot be inferred is a WARN (possible sex-chromosome aneuploidy such as XXY or X0, or low coverage).
  • Raw Mendelian error rate among trio-variant autosomal sites, computed by trio-dnm call: typically 0.5–2 %; > 5 % indicates a swap or contamination. Over ≥ 1000 informative sites (qc.mie_min_sites) this halts call (§3.3); below that (small panels) the gate is not applied, but the rate and a warning are still reported in the call summary and HTML report.

4. Stage 2 — Read Processing, Alignment and BQSR

4.1 Alignment

bwa-mem2 mem -t 16 -K 100000000 -Y \
    -R "@RG\tID:${fc}.${lane}\tSM:${sm}\tLB:${lb}\tPL:ILLUMINA\tPU:${fc}.${lane}.${barcode}" \

-Y soft-clips supplementary alignments; -K fixes the batch size so output is deterministic across thread counts. In the reference workflow modules/align.nf runs this stage when the sample sheet gives FASTQ: fastp and FastQC, BWA-MEM2 with the full read group above, duplicate marking and BQSR. BAM/CRAM input skips it.

4.2 Duplicate marking

GATK MarkDuplicates or MarkDuplicatesSpark (optical distance 2500 for patterned flow cells). Duplication should be < 15 % for PCR-free WGS and < 25 % for WES; higher rates inflate apparent allele support and must be flagged.

4.3 Base-quality recalibration

Required for the GATK path (dbSNP + Mills + 1KG sites; confirm flattened residuals with AnalyzeCovariates). DeepTrio/DeepVariant are trained on un-recalibrated qualities and should be given the pre-BQSR BAM or run with BQSR disabled. Archive as reference-based CRAM after verifying round-trip checksums.

5. Stage 3 — Joint Trio Variant Calling

5.1 Per-sample GVCFs (corrected command)

# PCR-free library: disable the PCR indel model. Keep comments OFF continued lines.
gatk --java-options "-Xmx14g" HaplotypeCaller \
    -R ${REF} -I ${BAM} -O ${SM}.g.vcf.gz \
    -ERC GVCF \
    --pcr-indel-model NONE \
    -G StandardAnnotation -G StandardHCAnnotation -G AS_StandardAnnotation \
    -A StrandBiasBySample \
    --max-alternate-alleles 6 \
    -L ${INTERVALS}

Do not add --output-mode EMIT_VARIANTS_ONLY: in GVCF mode it strips the reference blocks that prove each parent is hom-ref. -A StrandBiasBySample is optional: FORMAT/SB feeds the FS/SOR site annotations, but GenotypeGVCFs does not carry it into the joint VCF, so per-sample strand counts for Layer 2 come from a candidate-site pileup (§7.2).

WES/panels: restrict to targets ± 100 bp. WGS: scatter across ~50 interval shards. Sex chromosomes: calling male chrX/chrY non-PAR with --sample-ploidy 1 is optional — trio-dnm treats diploid 1/1 calls there as hemizygous.

5.2 Joint genotyping

gatk GenomicsDBImport -V proband.g.vcf.gz -V father.g.vcf.gz -V mother.g.vcf.gz \
    --genomicsdb-workspace-path trio_db -L ${INTERVALS} --merge-input-intervals
gatk GenotypeGVCFs -R ${REF} -V gendb://trio_db -O trio.vcf.gz \
    -G StandardAnnotation -G AS_StandardAnnotation \
    --only-output-calls-starting-in-intervals -L ${INTERVALS}

Joint genotyping is essential: it recovers low-confidence parental ALT evidence that distinguishes inherited variants from DNMs.

Normalise (bcftools norm -m -any -f ref.fa) and annotate gnomAD v4.1 joint AF (AF_joint, AF_grpmax_joint), ClinVar and the in-house panel of normals (PON_AF) with vcfanno (conf/vcfanno.toml); trio-dnm call takes this annotated VCF. In parallel run DeepTrio + GLnexus.

Use the union of GATK and DeepTrio Mendelian-violation sites for candidate discovery. The union drives DeNovoGear and TrioDeNovo (§6), and the normalised, vcfanno-annotated DeepTrio VCF is passed to trio-dnm call --extra-vcf: its Mendelian-violation records that are absent from the GATK VCF go through the same cascade and are flagged SECOND_ENGINE_ONLY. They lack the GATK site annotations and hiConfDeNovo, so they need IGV review. Agreement between engines is counted as evidence in §6.5 rather than used as a pre-filter.

6. Stage 4 — Multi-Caller De Novo Detection

Each caller models the trio differently; agreement is the strongest single false-positive reducer. DeNovoGear and TrioDeNovo are run only at the candidate sites from §5.3, which keeps them tractable on WGS. The same sites are piled up from the three BAMs (bcftools mpileup -a AD,ADF,ADR) for the Layer-2 strand test (§7.2).

gatk CalculateGenotypePosteriors -V trio.filtered.vcf.gz -ped trio.ped \

6.2 DeNovoGear

dng dnm auto --ped trio.ped --vcf cand.vcf on the joint-called candidate VCF (genotype likelihoods, PL), the same input as TrioDeNovo. Do not feed DeNovoGear a bcftools mpileup BCF: version 1.1.1 reads only the legacy samtools-0.1 BCF1 format. Keep pp_dnm ≥ 0.5 as caller support (bin/dng2tsv.py).

6.3 TrioDeNovo

triodenovo --ped trio.ped --in_vcf cand.vcf --out_vcf out.vcf --minDQ 7 on the joint-called candidate VCF (uses PL).

6.4 DeepTrio

Deep-learning trio caller (Kolesnikov 2021) with dedicated Illumina WGS, Illumina WES and PacBio models trained on GIAB trios; select --model_type by data type. Particularly strong for indels and low-complexity sequence. Mendelian-violation sites from the GLnexus-merged trio are the DeepTrio call set: they count as DeepTrio support (--caller deeptrio=…), and DeepTrio-only sites enter the cascade through --extra-vcf (§5.3). GLnexus writes BCF; convert it with bcftools view -Oz, because trio-dnm reads VCF only.

7. Stage 5 — Layered Filter Cascade

trio-dnm call takes the normalised, vcfanno-annotated joint VCF (§5.3), evaluates every Mendelian-violation candidate against all layers and records every failure reason in candidates.tsv; the waterfall in call_summary.json counts each candidate once, at the first layer it fails. Two read-level checks cannot be computed from a VCF and are covered elsewhere (§7.2). Defaults are for 30× PCR-free WGS; --data-type wes|panel applies the capture presets, and any threshold can be overridden with a JSON config (--config, containing only the keys you change).

Routing to the post-zygotic mosaic track requires both a proband VAF significantly below 0.5 (one-sided binomial p < 10⁻³, n = ref + ALT reads) and VAF < 0.40 (mosaic.max_vaf). A low-VAF candidate whose test is not significant stays in the germline track, fails the heterozygous VAF range and is flagged POSSIBLE_MOSAIC_NEEDS_DEPTH for review. 7.2 Layer 2 — Read and alignment quality

  • Site FILTER must be PASS (or .): a FILTER set by the §5.3 hard filters or VQSR/VETS fails the site as site_filter:<FILTER> (config site.honour_filter).
  • MQ ≥ 40; FS < 60 (SNV) / < 200 (indel); SOR < 3 (SNV) / < 10 (indel).
  • MQRankSum ≥ −12.5; ReadPosRankSum ≥ −8 (SNV) / ≥ −20 (indel).
  • Proband ALT reads on both strands (≥ 1 each, ≥ 2 preferred) and per-sample strand Fisher p ≥ 10⁻³. GenotypeGVCFs does not carry FORMAT/SB into the joint VCF and HaplotypeCaller writes no ADF/ADR, so the strand counts come from bcftools mpileup -a AD,ADF,ADR of the three BAMs at the candidate sites, passed as trio-dnm call --strand-vcf. FORMAT/SB or ADF/ADR in the joint VCF are used when present; with neither the candidate is flagged NO_STRAND_INFO.
  • Soft-clipped read fraction < 30 % where an INFO key supplies it (site.softclip_info_key, default SCF).
  • Not computed by trio-dnm from the VCF: indel support from ≥ 2 distinct read start positions (PCR stutter) and ALT reads concentrated in the terminal 10 % of read length. For germline candidates these are covered by ReadPosRankSum plus the mandatory IGV review before validation; for mosaic candidates by MosaicForecast's read-level features (§9.1).

7.3 Layer 3 — Genomic region exclusion (hard masks)

  • ENCODE blacklist v2; GIAB stratifications: low mappability, segmental duplications, tandem repeats / low complexity; in-house recurrent-artefact and pseudogene masks.
  • Homopolymer run ≥ 8 bp (SNV) or ≥ 6 bp (indel), computed from the reference around the site.
  • Within ± 5 bp of a reference N stretch.

7.4 Layer 4 — Population and recurrence

  • gnomAD v4.1 joint AF < 1 × 10⁻⁴, read from the vcfanno INFO key (gnomAD_AF; config population.af_keys). A ClinVar P/LP match is flagged POP_AF_RESCUED_BY_CLINVAR rather than removed: recurrent pathogenic DNMs at hypermutable CpGs, and CH variants in gnomAD blood donors, can appear at low counts.
  • If no record of the input VCF carries a gnomAD AF key, this filter cannot act: call prints a warning and records population_af_missing: true in call_summary.json. Annotate with vcfanno first.
  • In-house panel of normals (≥ 100 unrelated, identically processed): AF ≤ 0.01, read from a --pon VCF or from the vcfanno INFO key PON_AF (population.pon_info_key).
  • Recurrence in ≥ 5 unrelated trios in project history: removed as a likely artefact unless ClinVar P/LP (then flagged as a known recurrent pathogenic site).

7.5 Layer 5 — Bayesian trio posterior

trio-dnm computes the posterior from the joint-VCF genotype likelihoods (PL; a binomial read model with 1 % error when PL is absent), summing over every joint genotype configuration:

P(DNM | D) = Σ_{g_c>0} P(D_f|0) P(D_m|0) P(D_c|g_c) π(0)π(0) T(g_c|0,0)  /  Σ_{g_f,g_m,g_c} (same terms)
 
π(g)          Hardy–Weinberg prior with q = max(gnomAD AF, 1e-4)   (floor keeps absent sites conservative)
T(g_c|g_f,g_m) Mendelian transmission with per-allele mutation μ = 1.2e-8 (SNV) / 1e-9 (indel)
ploidy         taken from the region table in §7.1 (hemizygous child: single transmitting parent)
  • Retain candidates with posterior ≥ 0.80; the tiers use posterior ≥ 0.95 and hiConfDeNovo as set out in §6.5.
  • For the mosaic tracks a two-class read model (true event at observed VAF vs sequencing error 0.5 %) replaces the diploid model, multiplied by the probability that each parent does not carry the event at that VAF.

7.6 Layer 6 — Call-set integrity (replaces v1.0 kinship-on-DNMs)

  • Parental leakage: fraction of germline DNMs with any ALT read in each parent. An asymmetric excess (e.g. father 25 %, mother 3 %) points to contamination, a swap or under-sequencing of that parent.
  • Raw Mendelian error rate (§3.2) recorded per trio with the number of informative sites; > 5 % over ≥ 1000 sites halts the run (stop-gate, §3.3).
  • Allele balance: median proband VAF of germline DNMs should be 0.42–0.58 (sanity.median_vaf_range; checked by annotate when ≥ 10 DNMs).
  • Clustering: DNMs within 20 kb are flagged CLUSTERED_DNM for review (complex events, MNVs, maternal-age-associated clusters, or mapping artefacts).

8.2 Parent of origin

Phase with unfazed (read-backed and extended read-backed phasing using informative heterozygous sites). Expect 75–80 % paternal among phased SNV DNMs. Report the fraction with its Wilson 95 % CI and the number phased; alarm only when ≥ 10 are phased and the fraction lies outside 65–90 %.

8.3 Mutation spectrum and signatures

  • CpG transitions: 10–25 % of SNV DNMs (≈ 15–20 % expected).
  • Ti/Tv: 1.7–2.5 (WGS); 2.2–3.5 (WES).
  • SBS-96 spectrum refit to SBS1 + SBS5 + SBS40a by non-negative least squares; report exposures and reconstruction cosine. Unexpected signatures (e.g. SBS17, platinum SBS31/35) indicate artefact or exposure.

8.4 Indel properties

1–4 bp events should dominate; insertion:deletion ≈ 1:1 in unique sequence. A deletion excess concentrated in repeats indicates homopolymer/STR leakage (tighten Layer 3).

9. Stage 7 — Mosaic-Aware Tracks

9.1 Coverage and callers

Reliable detection at VAF 0.05 needs ≥ 200×; standard 30× WGS detects VAF ≳ 0.15–0.20 with modest sensitivity. For mosaic-focused studies deepen the proband by PCR-free targeted or duplex/UMI resequencing. Two complementary routes run in parallel:

  • Within trio-dnm call: low-VAF candidates present in the joint VCF (routed as in §7.1), filtered with the mosaic thresholds below.
  • Mutect2 tumour-only → MosaicForecast on the proband (SNVs with VAF 0.03–0.40, Refine model), then parental absence asserted from parental BAM pileups. MosaicForecast's read-level features (read position, base and mapping quality, clipping, strand) cover the read-position checks that trio-dnm cannot compute. DeepMosaic may be added for sensitivity at VAF 0.05–0.20.

9.2 Mosaic filters

  • Proband ALT reads ≥ 3 and VAF ≥ 0.05 (0.02 for deep panels).
  • Both parents: DP ≥ 30 (hemizygous father ≥ 15) and zero ALT reads.
  • ALT on both strands (Fisher p > 10⁻³; strand counts as in §7.2).
  • ALT reads not concentrated in the terminal 10 % of read length: not computed by trio-dnm; covered by MosaicForecast on the Mutect2 route and by IGV review on the trio-dnm call route.

9.3 VAF classification

Use a one-sided binomial test of ALT reads against 0.5 and report the Wilson 95 % CI, instead of fixed VAF bins. Significantly sub-heterozygous VAF indicates post-zygotic origin; the lower the VAF, the later (or more lineage-restricted) the event. A non-significant result at 0.30–0.45 is compatible with a heterozygote and must not be called mosaic without deeper data; trio-dnm call therefore routes a candidate to the mosaic track only when the test is significant and VAF < 0.40 (§7.1).

9.4 Parental mosaicism (new)

A proband heterozygote whose parent shows ALT reads significantly above sequencing error (binomial p < 10⁻⁴, ≥ 2 ALT reads, VAF ≤ 0.25) is not discarded; it is reported in the parental_mosaic track. This includes parents that the joint caller genotyped 0/1 but whose VAF is ≤ 0.25 and significantly below 0.5 (binomial p < 10⁻³); such candidates are flagged PARENT_CALLED_HET. These variants carry substantial recurrence risk and should be confirmed by ddPCR or deep amplicon sequencing in parental blood, buccal and — for fathers — sperm.

9.5 Clonal haematopoiesis as a confounder

Blood-derived DNA from adult probands and from parents can carry CH clones (DNMT3A, TET2, ASXL1, PPM1D, TP53, JAK2, SF3B1, SRSF2 …) at 2–35 % VAF. A low-VAF "DNM" in a CH gene in an adult proband, or parental ALT reads at such a site, should be treated as CH until shown otherwise in a non-haematopoietic tissue. The CH screen (§11.7) is run on all trio members for this reason.

10.5 Non-coding DNMs

Non-coding DNMs (≈ 98 % of WGS DNMs) are reported as Tier 5 and ranked by cCRE overlap, conservation (phyloP), CADD and proximity to phenotype-relevant genes. Interpretation is research-grade unless supported by functional data (MPRA, reporter assays, CRISPRi).

  • LoF-intolerant: pLI ≥ 0.9, gnomAD v4 LOEUF < 0.6, s_het ≥ 0.1, or ClinGen HI score 3.

11.3 Copy number, purity and clonality

  • Allele-specific copy number with CNVkit (call -m clonal with SNP B-allele frequencies) or PURPLE/FACETS; purity/ploidy from the same tool or pathology.
  • Cancer-cell fraction: CCF = VAF × (p·CN_t + 2(1 − p)) / (p · m), with purity p and local total copy number CN_t. The multiplicity is estimated per variant as m = clamp(round(VAF · (p·CN_t + 2(1 − p)) / p), 1, major CN). CCF is capped at 1 (ccf); the uncapped value is reported as ccf_raw. A variant is clonal when the upper 95 % bound of CCF ≥ 0.8.
  • LOH (minor CN = 0; copy-neutral or deletion) is recorded for each somatic variant (loh column) and at each germline hit position for two-hit analysis (§11.5).

11.4 Mutational burden, signatures and MSI

  • TMB = PASS non-synonymous somatic SNVs/indels per callable coding Mb (default 30 Mb for exomes; set to your callable territory). TMB-high ≥ 10/Mb.
  • SBS-96 spectrum and NNLS refit to COSMIC v3.4, with reconstruction cosine. Below 50 PASS SNVs a full-catalogue fit over-fits, so the refit is skipped unless a biologically plausible subset is given (--signature-subset).
  • MSI with MSIsensor-pro on the pair; mismatch-repair or POLE signatures (SBS6/15/26/44, SBS10a/b) cross-checked against germline MMR/POLE findings.

11.5 Driver and two-hit analysis

  • Drivers: curated hotspots (cancerhotspots, COSMIC) and damaging variants in COSMIC Cancer Gene Census genes; OncoKB/CIViC levels where licensed.
  • Two-hit detection: a gene with a Tier 1/2 or P/LP germline variant (from §10: de novo, or inherited when an annotated inherited-variant table is supplied) plus a PASS somatic SNV/indel in the same gene and/or LOH (minor CN = 0) at the germline variant position is reported as a candidate Knudson second hit (<tumor>.two_hit.tsv) — the key link between the trio germline result and the tumour. Germline + LOH is reported even without a somatic point mutation; LOH alone, without a germline hit, is recorded (loh column) but is not a second hit.

11.6 Affected tissue vs blood (use case B)

The same paired workflow is run with --mode tissue; PASS variants are labelled SOMATIC_MOSAIC. Expect low VAF (often 1–10 %): deepen to ≥ 500× with targeted/UMI sequencing of candidate genes, and confirm by ddPCR in a second piece of lesional tissue.

11.7 Clonal haematopoiesis screen (use case C)

Mutect2 in tumour-only mode on each blood sample, restricted to a CH gene panel, with PoN and germline resource, then VEP; trio-dnm ch-screen reports HIGH/MODERATE-impact variants (from the VEP CSQ, preferred) in CH genes at VAF 2–35 % (≥ 3 ALT reads) with Wilson CIs. Without a CSQ header the gene is read from an INFO key (--gene-info-key, default GENE), impact cannot be assessed and the impact filter is skipped, with a warning in the summary. Hits are cross-referenced with the DNM and mosaic tracks.

11.8 Somatic validation

Validate reportable somatic variants by an orthogonal method (amplicon-UMI sequencing or ddPCR), in a second tumour region where available, and in the matched normal to confirm absence.

Raw data to controlled-access archives (dbGaP, EGA) under appropriate consent. Clinically relevant variants to ClinVar; research DNMs to community resources (denovo-db, GeneMatcher/Matchmaker Exchange) after de-identification.

15. Reference Implementation Map

The repository trio_dnm_pipeline/ implements this protocol. The Python engine is dependency-free and covered by an automated test suite on a synthetic trio (true DNM, parental leakage, parental mosaic, proband mosaic, common variant, masked region, homopolymer, low MQ, inherited, male chrX hemizygous DNM), annotation/ACMG scenarios, somatic, CH, QC-gate and parser tests. Every Nextflow process has a stub block; stub dry runs on bundled placeholder inputs (nextflow run main.nf -stub -profile test_stub, and with -params-file tests/nextflow/params_fastq.yaml for FASTQ input) complete without failures on Nextflow 24.10.4. The workflow has not yet been executed with the real tools and must be validated on GIAB trio HG002/HG003/HG004 before production use. trio-dnm tasks stage the trio_dnm package into each task directory and put it on PYTHONPATH, so they run in any Python ≥ 3.10 image (default python:3.11) or in the image built from the provided Dockerfile. Every resource file (with any index next to it) is staged into the tasks as a Nextflow path input, so it is visible inside Docker/Singularity containers without bind mounts (see the header of nextflow.config).
